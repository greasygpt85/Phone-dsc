How to use
  1. Mount phone along the telescope tube; avoid large metal nearby for better compass accuracy.
  2. Tap Get Location (requires HTTPS) or Use Gulfport, MS, or enter lat/lon then Save Loc.
  3. Tap Enable Motion/Compass and grant permission.
  4. Calibrate altitude: set Horizon then Zenith. Align azimuth on a known object using Align to Selected.
  5. Select a target and follow arrows until both read 0°.

iPhone: Settings → Privacy & Security → Location Services → Safari Websites → While Using (+ Precise Location). Settings → Safari → Location → Allow.
